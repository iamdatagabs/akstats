01 / O PROJETO

Uma pergunta clínica.
Uma investigação molecular.

A queratose actínica (AK) é uma lesão relacionada à exposição ultravioleta e pode integrar o espectro de progressão para o carcinoma espinocelular cutâneo (cSCC). O AKStats organiza e reanalisa dados públicos para explorar alterações em ARID2, regulador associado à cromatina, e em genes relacionados à sinalização MAPK.

O projeto combina engenharia de software, bioinformática e análise estatística para tornar o percurso analítico rastreável: dos dados de origem às tabelas, figuras e relatórios.
